Ride Income & Expense Tracker
================================
Tech: PHP 8+, MySQL, Bootstrap 5, JavaScript, XAMPP

1. Copy this folder to C:\xampp\htdocs\
2. Start Apache and MySQL in XAMPP.
3. Open http://localhost/phpmyadmin
4. Import database.sql
5. Open http://localhost/ride_income_expense_tracker/
6. Register a user and start adding income/expenses.

Database settings are in config/db.php:
host=localhost, user=root, password='', database=ride_tracker
